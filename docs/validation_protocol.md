# بروتوكول التحقق العام

كل مرحلة يجب أن تحتوي على خمسة مستويات قبل الانتقال:

1. **مراجعة التعريف:** المعادلات، الوحدات، اتفاقية الإشارات، وترتيب المحاور مكتوبة.
2. **Unit tests:** حالات صغيرة تحدد السلوك عند الحدود والفشل.
3. **Synthetic test:** هندسة معروفة أو phantom يسمح بقياس الخطأ مقابل قيمة صحيحة.
4. **Real-data integration:** تشغيل على Pilot TCIA واحد على الأقل، مع حفظ config والنتائج.
5. **Acceptance report:** ما نجح، ما فشل، حدود الصلاحية، وإصدار الكود وhash البيانات.

## قاعدة الفشل

ممنوع fallback صامت إلى backend أو طريقة تقريب أخرى. إن لم تتوفر CUDA مثلًا، يسجل التقرير أن الاختبار لم يعمل على GPU؛ لا يغيّر البرنامج طريقة الحساب دون أن يعرف المستخدم.

## المقاييس الدنيا المستقبلية

- خطأ إعادة الإسقاط واتساق الوحدات.
- اختبار adjoint مستقل لـ forward/backprojector، وليس gradient ذاتيًا لنفس الدالة فقط.
- فرق curved-to-flat وSSRB عن مرجع بطيء scalar.
- نسبة measured/missing لكل slice بعد SSRB.
- PSNR/SSIM/RMSE وقياسات ROI/MTF أو NPS عند توفر phantom مناسب.
