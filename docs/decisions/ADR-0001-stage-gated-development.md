# ADR-0001: تطوير مرحلي ببوابات قبول

- **الحالة:** مقبول
- **القرار:** لا يبدأ تطوير SSRB قبل قبول قارئ البيانات والهندسة، ولا يبدأ التعلم الآلي قبل قبول reference FBP والمحاكاة.
- **السبب:** خطأ بسيط في ترتيب المحاور أو pitch قد يبدو للشبكة مشكلة تعلم، فتنتج نتائج جميلة لكنها غير صحيحة فيزيائيًا.
- **الأثر:** التطوير أبطأ في البداية لكنه قابل للدفاع العلمي وإعادة الإنتاج.
